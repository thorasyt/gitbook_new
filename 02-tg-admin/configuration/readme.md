# Configuration Guide

The configuration files for `tg-admin` allow server owners to customize key mappings, administrative permissions, display preferences, custom chat commands, logging integrations, and vehicle customization/ped models lists.

---

### Configuration Files

`tg-admin` separates configuration settings into four main scopes matching the codebase setup:

*   [🔌 Client Configuration](client.md) — Configures default hotkey bindings and minimum client-side feature permissions.
*   [🤝 Shared Configuration](config.md) — Configures translation locales, HUD overlay limits, custom styling colors/presets, and ped spawning model lists.
*   [⚙️ Server Configuration](server.md) — Configures server action permissions, shorthand chat commands, and administrative audit logging triggers.
*   [🛠️ Shared Functions](functions.md) — Manages translation loaders, menu ID formatters, notification wrappers, and chat integrations.
