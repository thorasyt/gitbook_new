## Controls & Commands

### Commands
| Command | Permission | Description |
|---|---|---|
| `/edithud` | Everyone | Opens the HUD customization menu and drag-and-drop editor |
| `/togglehud` | Everyone | Toggles entire HUD visibility on or off |

### Default Keybinds
| Key | Action | Description |
|---|---|---|
| `B` | `toggle_seatbelt` | Buckle / unbuckle vehicle seatbelt (customizable in GTA Key Bindings) |
| `J` | `toggle_cruise` | Enable / disable cruise control (customizable in GTA Key Bindings) |
